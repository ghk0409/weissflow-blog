위험천만한 자동매매 봇을 버리고, 24/7 AI 금융 비서로 피벗한 이유

[Post 01] 위험천만한 자동매매 봇을 버리고, 24/7 AI 금융 비서로 피벗한 이유

"수익률에 눈멀어 만든 자동매매 봇이 계좌를 태우기 직전, 나는 코드를 전부 뒤엎었다."

1. Hook & Pain Point: 잠 못 들던 밤들과 블랙박스의 배신

개발자라면 누구나 한 번쯤 꿈꿉니다.

"내가 자는 동안에도 백그라운드에서 알고리즘이 24시간 거래를 체결하며 돈을 복사해 주는 시스템."

저 역시 그랬습니다. 주식과 암호화폐 거래소의 REST/WebSocket API를 엮고, 이동평균선(SMA), 볼린저 밴드, RSI 다이버전스를 결합한 자동매매 봇을 개발했습니다. 백테스팅 결과는 완벽해 보였습니다. 샤프 비율(Sharpe Ratio) 2.1, 연환산 기대수익률 48%. 저는 자신만만하게 실계좌에 봇을 배포하고 잠자리에 들었습니다.

하지만 실전 금융 시장은 백테스트 화면처럼 친절하지 않았습니다.

마주해야 했던 냉혹한 현실들

1. 슬리피지(Slippage)와 호가 공백: 변동성이 폭발하는 순간 시장가 주문이 체결되면서 상상 이상의 손실이 발생했습니다.

2. 블랙스완과 비정형 데이터: 알고리즘은 차트 지표만 볼 뿐, 미 연준(Fed) 파월 의장의 긴급 발언, 도널드 트럼프의 관세 폭탄 발언, 상장폐지 심사 등 텍스트 기반의 거시 충격을 전혀 이해하지 못했습니다.

3. 심리적 파탄: "봇이 지금 무슨 주문을 넣고 있을까?", "갑자기 API 랙이나 버그로 풀매수 루프가 돌면 어쩌지?" 스마트폰 화면을 10분마다 켜보느라 수면의 질은 최악으로 치달았습니다.

일임형 블랙박스 트레이딩 봇의 본질적인 모순
시장의 불확실성은 100% 코드로 통제할 수 없습니다. 인간의 직관과 맥락 판단이 완전히 배제된 자동 주문 시스템은 '수익 머신'이 아니라 언제 터질지 모르는 '시한폭탄'이었습니다.

결국 한밤중 발생한 예기치 못한 시장 급락으로 수백만 원의 손실을 입은 날, 저는 모든 주문 프로세스를 강제 종료(Kill Switch)했습니다. 그리고 스스로에게 질문을 던졌습니다.

**"내가 진짜 원했던 건 '내 돈을 마음대로 굴리는 통제 불능의 봇'인가,
아니면 '시장과 데이터를 24시간 감시하고 최적의 맥락을 보고해 주는 똑똑한 파트너'인가?"**

이 질문이 바로 WeissFlow의 첫 번째 아키텍처 결정(ADR 0001: Pivot to AI Financial Copilot)의 시작이었습니다.

2. Architecture: "운전대(Execution)" 대신 "내비게이션(Context)"을 맡기다

우리의 전략은 180도 바뀌었습니다.

"AI에게 최종 주문 권한을 주지 않는다. 대신 인간의 인지 능력을 초월하는 멀티 채널 데이터 수집과 맥락 브리핑을 맡긴다."

이것이 바로 Human-in-the-Loop(인간 참여형) AI 금융 코파일럿 아키텍처입니다.

아키텍처 핵심 원칙

1. Zero Autonomous Order (자율 주문 전면 금지): 시스템은 어떠한 경우에도 매수/매도 트랜잭션을 독단적으로 서명하거나 전송하지 않습니다.

2. Actionable Suggestions (실행 가능한 제안): 단순 텍스트 알림("삼성전자 실적 발표됨")에 그치지 않고, ActionPayload 구조체에 타깃 종목, 추천 비중, 진입 기준선, 위험 헤지 방안을 담아 유저 화면에 버튼 형태로 렌더링합니다.

3. Contextual Synthesizer (맥락 종합기): 단편적인 가격 변동이 아니라 공시, 환율, 나스닥 선물 지수와의 상관관계를 3줄로 압축 브리핑합니다.

3. Deep Dive: LLM 토큰 비용 폭탄을 막는 에이전틱 문서 체계

AI 코파일럿으로 전환하면서 맞닥뜨린 첫 번째 기술적 장벽은 "LLM 컨텍스트 윈도우 한계와 API 비용 폭탄"이었습니다.

24시간 수많은 지표를 실시간으로 LLM에 날것 그대로 전달하면, 분당 수만 토큰이 소모되며 하루 API 비용만 수십 달러가 넘어가게 됩니다. 또한 이전 대화 기록이나 시장 히스토리가 길어질수록 모델은 과거 정보에 혼동을 겪는 '컨텍스트 드리프트(Context Drift)' 현상을 겪습니다.

이를 해결하기 위해 우리는 ADR 0002: Agentic Documentation & Token Efficiency를 수립하고, 2단계 인메모리 압축 프로토콜을 구현했습니다.

토큰 압축 엔진 코드 스니펫

python
# core/context/token_reducer.py
from dataclasses import dataclass
from typing import List, Dict, Any

@dataclass
class CompactMarketState:
    macro_risk_level: str  # "LOW" | "ELEVATED" | "CRITICAL"
    top_divergences: List[str]
    active_hedges: List[str]
    estimated_tokens: int

class AgenticContextReducer:
    """원시 시장 시그널을 LLM 주입용 500토큰 이내의 정형 마크다운으로 압축하는 리듀서"""
    
    def __init__(self, max_token_budget: int = 500):
        self.max_token_budget = max_token_budget

    def build_current_state(self, raw_signals: List[Dict[str, Any]]) -> str:
        # 1. 시그널 중요도(Severity) 기반 가중치 정렬
        high_priority = [s for s in raw_signals if s.get("severity") in ("CRITICAL", "HIGH")]
        medium_priority = [s for s in raw_signals if s.get("severity") == "MEDIUM"]
        
        # 2. 극단적 불릿 요약 생성 (LLM 호출 비용 0원)
        lines = ["### [SYSTEM STATUS - LIVE SNAPSHOT]"]
        lines.append(f"- Macro Risk: {self._evaluate_macro_regime(raw_signals)}")
        
        for sig in (high_priority + medium_priority)[:5]:
            lines.append(
                f"* [{sig['asset']}] {sig['metric']}: {sig['value']} "
                f"(Δ {sig.get('change_pct', 0):+.2f}%) -> {sig['action_hint']}"
            )
            
        summary_md = "\n".join(lines)
        return summary_md

    def _evaluate_macro_regime(self, signals: List[Dict[str, Any]]) -> str:
        volatility = any(s.get("metric") == "VIX" and s.get("value", 0) > 25 for s in signals)
        if volatility:
            return "⚠️ HIGH VOLATILITY REGIME (Hedge Priority)"
        return "🟢 STABLE / TREND FOLLOWING"

이 설계로 얻은 효과

  • 토큰 사용량 88% 감소: 회당 평균 6,500토큰 -> 750토큰으로 극적 절감.
  • 추론 지연 시간(Latency) 단축: 4.8초 -> 0.8초 이내로 단축되어 실시간 알림 파이프라인 완성.
  • Gemini API 비용: 월간 \$150 예상치에서 \$4.5 수준으로 하락 (무료 티어 내 소화 가능 수준 달성).

4. Troubles & Lessons: AI에게 어디까지 맡길 것인가?

트러블슈팅: "AI가 추천한 포지션이 틀렸을 때의 심리적 저항"

피벗 초기, AI 코파일럿이 "김치프리미엄 4.2% 급등에 따른 차익 실현 제안"을 화면에 띄웠지만, 저는 과거 손실 기억 때문에 선뜻 승인 버튼을 누르지 못했습니다.

우리는 이를 시스템 신뢰의 문제로 규정하고 다음의 엔지니어링 보완책을 도입했습니다:

1. Explainable Rationale (추천 근거 3원칙 명시):

  • "왜 지금인가?" (과거 30일 김프 평균 대비 +2.8σ 표준편차 초과)
  • "최악의 시나리오는 무엇인가?" (환율 1% 급락 시 예상 손익 -0.4%)
  • "청산 탈출구(Exit Strategy)는 정의되어 있는가?" (김프 1.5% 수렴 시 자동 알림)

    • 2. 사후 검증 저널(Brier Score Journal):

  • 코파일럿의 예측과 실제 시장 결과를 사후에 비교하여 예측 적중률(Brier Score)을 투명하게 계산하고 로깅했습니다. (이 내용은 ADR 0021에서 다룹니다.)

핵심 교훈 (Lessons Learned)

  • 자율성(Autonomy)보다 중요한 것은 가시성(Observability)이다.
  • AI는 펀드매니저가 아닙니다. AI는 지치지 않고 24시간 동안 방대한 잡음(Noise) 속에서 의미 있는 신호(Signal)를 건져 올리는 최고의 수석 분석관(Chief Research Analyst)이어야 합니다.

5. Takeaways & Next Steps

1. 자동매매 봇의 환상을 버리세요. 개인 개발자가 슬리피지, 지연 시간, 블랙스완 속에서 기관의 HFT(고빈도 매매) 봇을 이기기는 불가능에 가깝습니다.

2. Human-in-the-Loop AI 코파일럿으로 전환하세요. AI에게는 24/7 데이터 수집, 정규화, 맥락 요약을 맡기고, 최종 실행과 리스크 감수는 인간이 담당할 때 비로소 평온한 수면과 높은 수익률을 동시에 챙길 수 있습니다.

3. 에이전틱 상태 압축 프로토콜을 구축하세요. 날것의 데이터를 LLM에 던지지 말고, 가벼운 코드 기반 리듀서를 거쳐 최소한의 핵심 토큰만 주입해야 지속 가능한 개인 AI 시스템을 유지할 수 있습니다.
