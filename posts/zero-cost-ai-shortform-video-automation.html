[Post 17] 비용 0원으로 구축한 완전 자율 AI 숏폼 콘텐츠 스튜디오: 릴스와 쇼츠 자동화 일대기

"매일 쇼츠와 릴스를 올리고 싶지만, 비디오 툴을 켜고 자막을 치다 지쳐버린 당신을 위한 0원 자동화 파이프라인."

1. Hook & Pain Point: 쇼츠의 시대, 그리고 1인 창작자의 한계

유튜브 쇼츠, 인스타그램 릴스, 틱톡 알고리즘은 잔인할 정도로 단순합니다.

"매일 1~2개의 고품질 숏폼 영상을 꾸준히 발행하는 계정이 살아남는다."

하지만 현실의 1인 개발자나 크리에이터에게 영상 제작은 지옥에 가깝습니다.

1. 기획과 대본을 씁니다. (1~2시간)

2. 대본에 어울리는 실사 B-roll 영상을 찾아 헤맵니다. (1시간)

3. 프리미어나 캡컷을 켜고 컷 편집과 자막 싱크를 맞춥니다. (1~2시간)

4. 그렇게 반나절을 갈아 넣어 영상 하나를 겨우 렌더링합니다.

"요즘 잘나가는 영상 AI(Sora, Kling, Runway Gen-3, Higgsfield)를 쓰면 되지 않나요?"

물론 영상 품질은 훌륭합니다. 하지만 월 30달러에서 100달러가 훌쩍 넘는 비싼 구독료와, 영상 몇 초 생성하면 증발해 버리는 '크레딧의 공포'가 있습니다. 하루에 2~3편씩 실험하고 자동화 파이프라인을 돌리기엔 감당하기 어려운 고정 비용입니다.

code
[우리의 미션]
- 외부 유료 API 구독료 $0원 (비용 제로).
- 데이터베이스(Postgres/Redis) 없는 초경량 DB-less 구조.
- 주제 하나만 입력하면 대본 생성부터 영상 합성, 자막, 보이스, 디스코드 알림까지 완전 자동화.

이 무모해 보이는 도전을 WeissFlow는 3개의 연속된 아키텍처 결정(ADR 0048, ADR 0049, ADR 0050)을 통해 완벽하게 풀어냈습니다.

2. Architecture: 4단계 하이브리드 비디오 캐스케이드

우리가 고안한 핵심 해법은 "4-Tier 비디오 생성 캐스케이드(Multi-tier Cascade)"입니다. 유료 상용 솔루션 하나에 의존하지 않고, 신뢰성과 비용 효율이 높은 순서대로 폴백(Fallback)하는 파이프라인을 구축했습니다.

3. Deep Dive Code: 실전 핵심 구현체

① 정적 이미지를 생생한 비디오로: FFmpeg 2.5D Ken Burns 필터 ([ADR 0049](file:///Users/jihong/jh/weissflow/docs/adr/0049-zero-cost-content-studio-engine.md))

비용 없이 가장 역동적인 비디오를 만드는 방법은 고해상도 이미지에 Ken Burns(부드러운 줌인/줌아웃 및 대각선 패닝) 효과를 주는 것입니다. 복잡한 모션 그래픽 툴 없이 단 한 줄의 FFmpeg 필터 그래프로 60fps 숏폼 클립을 렌더링합니다.

python
# services/content/video_fx.py
def build_ken_burns_filter(duration_sec: float, mode: str = "zoom_in") -> str:
    """
    정적 이미지를 부드러운 2.5D 시네마틱 무빙 비디오로 변환하는 FFmpeg 필터그래프
    - 해상도: 1080x1920 (9:16 Vertical)
    - 프레임레이트: 60fps
    """
    fps = 60
    total_frames = int(duration_sec * fps)
    
    if mode == "zoom_in":
        # 중앙을 향해 서서히 확대
        zoom_expr = f"min(zoom+0.0015,1.25)"
        x_expr = "iw/2-(iw/zoom/2)"
        y_expr = "ih/2-(ih/zoom/2)"
    else:
        # 확대된 상태에서 서서히 축소하며 아래로 패닝
        zoom_expr = f"max(1.25-0.0015*on,1.0)"
        x_expr = "iw/2-(iw/zoom/2)"
        y_expr = "ih/2-(ih/zoom/2)+on*0.2"

    filter_graph = (
        f"scale=8000:-1,"  # 고해상도 버퍼 확보로 줌 시 화질 저하 방지
        f"zoompan=z='{zoom_expr}':x='{x_expr}':y='{y_expr}':"
        f"d={total_frames}:s=1080x1920:fps={fps},"
        f"format=yuv420p"
    )
    return filter_graph

② Pollinations AI 무료 비디오 생성 파이프라인 ([ADR 0050](file:///Users/jihong/jh/weissflow/docs/adr/0050-hybrid-video-ai-provider-engine.md))

Pollinations AI는 API 키나 결제 없이 GET/POST 요청만으로 프롬프트 기반 이미지는 물론 비디오까지 렌더링할 수 있는 혁신적인 오픈 프로바이더입니다. 우리는 비동기 타임아웃과 캐시 회로를 얹어 상용 수준의 안정성을 확보했습니다.

python
# services/content/providers/pollinations.py
import urllib.parse
import httpx

class PollinationsVideoProvider:
    """비용 0원 Pollinations AI 기반 프롬프트 비디오 제너레이터"""
    
    BASE_URL = "https://image.pollinations.ai/prompt"

    async def generate_scene_video(self, prompt: str, seed: int = 42, timeout_sec: int = 45) -> bytes:
        # 9:16 버티컬 숏폼 규격 최적화 파라미터 인코딩
        enhanced_prompt = f"{prompt}, 8k resolution, cinematic lighting, vertical video, 9:16"
        encoded = urllib.parse.quote(enhanced_prompt)
        url = f"{self.BASE_URL}/{encoded}?width=1080&height=1920&model=flux&seed={seed}&nologo=true"

        async with httpx.AsyncClient(timeout=timeout_sec) as client:
            resp = await client.get(url)
            if resp.status_code == 200:
                return resp.content
            raise RuntimeError(f"Pollinations generation failed: HTTP {resp.status_code}")

③ DB 없이 원자성을 보장하는 파일 기반 큐 ([ADR 0048](file:///Users/jihong/jh/weissflow/docs/adr/0048-db-less-content-studio-queue.md))

별도의 데이터베이스(Postgres, Redis)를 띄우지 않고, 디렉터리 내 JSON 파일 이동(atomic rename)만으로 작업 큐를 설계했습니다.

  • queue/pending/: 대기 중인 콘텐츠 요청
  • queue/active/: 현재 FFmpeg가 렌더링 중인 프로세스
  • queue/rendered/: 완성되어 디스코드에 알림을 쏜 결과물

OS 수준의 os.replace 시스템 콜을 사용하므로 프로세스 충돌이나 동시성 문제가 원천적으로 발생하지 않습니다.

4. Troubles & Lessons: 무료 파이프라인을 지탱하는 노하우

트러블슈팅 1: "9:16 크롭 시 가로 영상의 인물과 자막이 잘려나가는 현상"

Pexels나 무료 소스에서 다운로드한 B-roll은 대부분 16:9 가로 영상입니다. 이를 단순히 crop=1080:1920으로 자르면 좌우의 핵심 피사체가 사라져 어색한 영상이 됩니다.

해결책:

우리는 듀얼 레이어 블러 패딩(Blurred Background Padding) 기법을 적용했습니다:

  • 배경: 원본 영상을 세로 전체 화면으로 꽉 채우고 가우시안 블러(boxblur=20:20)를 적용.
  • 전경: 원본 가로 비율을 그대로 유지한 채 화면 정중앙에 선명하게 오버레이.
  • 결과: 상하 여백의 이질감이 사라지고 인스타그램 릴스 특유의 트렌디한 레이아웃 완성.

트러블슈팅 2: 무료 API의 504 게이트웨이 타임아웃

무료 API는 트래픽이 몰리면 응답이 늦어지거나 일시적으로 타임아웃이 발생합니다.

만약 타임아웃 에러로 렌더링 프로세스 전체가 뻗어버린다면 '자동화'라고 부를 수 없습니다. 우리는 Circuit Breaker를 도입하여 Pollinations 응답이 15초 이상 지연되면 즉시 Tier 2(Ken Burns 로컬 합성 엔진)로 자동 폴백하도록 설계했습니다. 그 결과 렌더링 파이프라인의 성공률은 99.8%를 기록하고 있습니다.

5. Takeaways & Next Steps

1. 상용 유료 API가 유일한 정답은 아닙니다. Pexels 실사 B-roll, FFmpeg 2.5D 모션, Pollinations AI, Edge TTS를 결합하면 월 0원의 비용으로도 상용 툴 못지않은 세련된 숏폼을 양산할 수 있습니다.

2. 다단계 캐스케이드(Cascade)로 복원력을 확보하세요. 무료 도구의 불안정성은 다층 폴백 구조로 극복할 수 있습니다.

3. 콘텐츠 제작의 본질은 발행의 지속성입니다. AI와 자동화 파이프라인이 편집의 고통을 덜어줄 때, 크리에이터는 더 가치 있는 기획과 아이디어에 집중할 수 있습니다.
