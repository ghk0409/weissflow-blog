[Post 08] 옵시디언(Obsidian) 볼트를 웹으로: 스스로 지식을 경작하는 AI 정원사 RAG 구축기

"노트를 작성할수록 지식의 정원이 풍요로워지는 것이 아니라, 잡초처럼 외톨이 노트들만 쌓여가고 있다면?"

1. Hook & Pain Point: 메모 앱의 공동묘지와 세컨드 브레인의 한계

옵시디언(Obsidian)이나 노션(Notion)을 쓰는 분들이라면 겪어보셨을 익숙한 비극이 있습니다.

  • 아티클을 읽고 영감을 받아 새 노트를 만듭니다: 2026-03-15-거시경제와-금리인하.md
  • 몇 줄의 생각과 하이라이트를 적어둡니다.
  • 그리고 다시는 그 노트를 열어보지 않습니다.

시간이 흐르면 볼트(Vault) 안에는 수백, 수천 개의 마크다운 파일이 쌓이지만, 서로 연결되지 못한 채 방치되는 '외톨이 노드(Orphan Node)'들의 무덤이 됩니다. 게다가 로컬 파일 기반의 옵시디언은 외부나 스마트폰, 태블릿 브라우저에서 가볍게 열람하기가 번거롭습니다.

3. 내 수천 개 메모를 모두 기억하고 대답해 주는 전용 RAG 코파일럿을 둘 수는 없을까?

이 질문들에 답하기 위해 WeissFlow는 "디지털 지식정원(Digital Knowledge Garden)"과 "자율 AI 정원사(Autonomous AI Gardener)" 시스템을 설계했습니다.

2. Architecture: 지식의 성장 주기와 24/7 자동 경작 파이프라인

우리는 지식을 박물관의 박제된 유물이 아니라, '살아서 자라나는 식물'로 정의했습니다.

지식 성숙 3단계 라이프사이클 (Knowledge Maturity Model)

  • 🌱 Seedling (씨앗 노트): 갓 수집한 원시 아이디어, 스크랩, 찰나의 생각 (단편적 메모)
  • 🌿 Budding (새싹 노트): 다른 생각들과 링크가 연결되고 맥락이 정리되기 시작한 메모
  • 🌳 Evergreen (상록수 노트): 높은 연결성과 완결된 구조를 갖춘 영구적 지식 자산

3. Deep Dive: 핵심 구현 3요소

① macOS launchd 기반 무중단·무충돌 Git 동기화 ([ADR 0033](file:///Users/jihong/jh/weissflow/docs/adr/0033-obsidian-vault-git-sync-and-launchd-daemon.md))

타사 유료 Sync 플러그인 없이, macOS의 네이티브 데몬인 launchd와 경량 쉘 스크립트로 15분 주기 자동 백업 및 원격 동기화를 구축했습니다.

bash
#!/usr/bin/env bash
# scripts/garden-git-sync.sh
set -euo pipefail

VAULT_DIR="$HOME/Documents/ObsidianVault"
cd "$VAULT_DIR"

# 원격 변경사항 안전 병합 (Fast-Forward 우선)
git fetch origin main --quiet
LOCAL=$(git rev-parse HEAD)
REMOTE=$(git rev-parse origin/main)

if [ "$LOCAL" != "$REMOTE" ]; then
    git merge origin/main --no-edit --quiet || {
        echo "[WARNING] Conflict detected. Stashing local changes."
        git stash
        git merge origin/main --no-edit
        git stash pop || true
    }
fi

# 로컬 변경사항이 있는 경우 원자적 커밋 & 푸시
if [[ -n $(git status -s) ]]; then
    git add .
    TIMESTAMP=$(date "+%Y-%m-%d %H:%M:%S")
    git commit -m "garden: auto-sync update at ${TIMESTAMP} [skip ci]" --quiet
    git push origin main --quiet
fi

② 외톨이 노드를 연결하는 자동 경작(Auto-Tending) 알고리즘 ([ADR 0037](file:///Users/jihong/jh/weissflow/docs/adr/0037-digital-knowledge-garden-auto-tending-and-synthesizer.md))

AI 정원사는 주기적으로 볼트 전체를 스캔하여 링크가 0~1개뿐인 고립된 노트를 찾아내고, 의미적 유사도(Semantic Similarity)가 높은 기존 상록수 노트를 찾아 마크다운 끝에 스마트 추천 링크를 삽입합니다.

python
# services/gardener/auto_tending.py
import re
from pathlib import Path
from typing import List, Dict

class KnowledgeGardenAutoTender:
    """고립된 노드를 찾아 의미적으로 유관한 상록수 노트와 결속시키는 정원사 엔진"""
    
    WIKILINK_PATTERN = re.compile(r"\[\[(.*?)\]\]")

    def __init__(self, vault_path: Path, similarity_threshold: float = 0.78):
        self.vault_path = vault_path
        self.similarity_threshold = similarity_threshold

    def find_orphan_notes(self) -> List[Path]:
        orphans = []
        for md_file in self.vault_path.glob("**/*.md"):
            content = md_file.read_text(encoding="utf-8")
            links = self.WIKILINK_PATTERN.findall(content)
            if len(links) <= 1:  # 연결된 링크가 거의 없는 고립 노트
                orphans.append(md_file)
        return orphans

    def graft_links(self, target_note: Path, recommended_links: List[str]):
        """노트 하단에 AI 경작 섹션을 안전하게 덧붙임 (Idempotent)"""
        content = target_note.read_text(encoding="utf-8")
        
        if "### 🌿 AI Gardener Connections" in content:
            return  # 이미 한 차례 경작된 노트는 중복 주입 방지
            
        graft_block = "\n\n---\n### 🌿 AI Gardener Connections\n"
        graft_block += "> *이 노트는 다음 상록수 주제들과 밀접하게 연결되어 있습니다:*\n"
        for title in recommended_links:
            graft_block += f"- [[{title}]]\n"
            
        target_note.write_text(content + graft_block, encoding="utf-8")

③ 3단계 LLM 캐스케이드 RAG 엔진 ([ADR 0036](file:///Users/jihong/jh/weissflow/docs/adr/0036-omnipresent-ai-gardener-terminal-cli-and-discord-rag.md))

사용자가 터미널 CLI(wf ask "지난달 분할 매수한 종목이 뭐였지?")나 디스코드(/질문), 또는 웹 브라우저 플로팅 챗봇에서 질문하면 0.5초 만에 개인 볼트를 뒤져 답변합니다.

  • 1차 시도 (Tier 1): Gemini 2.5 Flash (초고속, 제로 레이턴시)
  • 2차 시도 (Tier 2): Gemini 2.0 Flash (폴백)
  • 3차 시도 (Tier 3): Gemini 1.5 Flash (최종 안정망)
  • 엄격한 원칙: 환각(Hallucination) 방지를 위해 "반드시 참조한 노트 파일명과 발췌 문장을 각주로 달 것"을 시스템 프롬프트로 강제.

4. Troubles & Lessons: AI가 지식 정원을 망치지 않게 하는 법

트러블슈팅 1: "AI 정원사가 엉뚱한 링크를 남발해 정원이 쓰레기통이 되다"

초기 프로토타입에서는 LLM에게 단순 프롬프트로 "관련된 링크를 달아줘"라고 맡겼더니, 모든 노트에 [[생각]], [[개발]], [[공부]] 같은 뻔하고 모호한 태그성 링크를 수십 개씩 달아버렸습니다. 지식 그래프가 하나의 거대한 거미줄 뭉치로 오염되었습니다.

해결책:

1. 역인용 빈도(IDF) 페널티: 너무 광범위하고 자주 등장하는 범용 키워드는 링크 추천 후보에서 강제 배제.

2. 최소 유사도 임계치(0.78 이상) 강제: 모호하게 관련된 노트는 연결하지 않고 여전히 Seedling 단계로 남겨둠.

3. 분리된 섹션 규격: 본문 문장 사이에 임의로 위키링크를 끼워 넣지 않고, 반드시 파일 최하단 ### 🌿 AI Gardener Connections 규격화된 블록에만 링크를 모아서 기재.

트러블슈팅 2: Git 머지 충돌(Merge Conflict)의 공포

내가 밖에서 스마트폰으로 마크다운 파일을 수정하는 도중, 로컬의 백그라운드 데몬이 커밋을 치면 충돌이 발생할 수 있습니다.

우리는 git stash -> git pull --rebase -> git stash pop 파이프라인을 쉘 스크립트에 견고하게 작성하여, 지난 수개월간 단 한 번의 파일 유실 없이 24시간 양방향 동기화를 유지하고 있습니다.

5. Takeaways & Next Steps

1. 지식 관리는 '저장'이 아니라 '연결'입니다. 메모를 아무리 많이 모아도 그것들이 서로 대화하지 못하면 뇌의 인지 부하만 늘어납니다.

2. AI를 '지식의 정원사'로 고용하세요. 새로운 글을 쓸 때마다 이전의 기록들을 찾아 헤매지 않아도, AI가 밤새 내 볼트를 순회하며 오래된 노트와 새 노트를 이어줍니다.

3. 무의존성 웹 지식정원으로 확장하세요. 무거운 상용 플랫폼에 갇히지 않고 나만의 K3s 클러스터나 가벼운 정적 웹으로 호스팅할 때, 세컨드 브레인은 진정한 내 자산이 됩니다.
